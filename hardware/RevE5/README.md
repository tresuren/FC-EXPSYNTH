# FC-EXPSYNTH (Rev.E5 — 作業中 / WIP)

**作業途中の版です。配線は未完成(自動配線の実行中)。発注には使えません。** 完成版は `hardware/RevE4/`。

## RevE4 からの変更(予定・一部実施済み)
- 基板を 92x60mm → **92x80mm** に拡大(RP2350 とバッファ列の間、バッファ列と接触指の間に余裕)。
- **PPU バス 27 本と /IRQ を J10(接触指)と J11(上部スロット)で直結**(上に刺したカセットのゲームを動かすため)。PPU の 27 本は裏面に縦の線として固定済み(`scripts/ppu_lanes.py`)。
- **ゲーム/演奏モード切替**: GPIO30 → GAME(10k プルアップ、既定=ゲームモード)。U14 の空きゲートと U15 の空きインバータで RW_SYN = R/W AND NOT GAME を作り、ROMSEL_EXP = ROMSEL_N OR RW_SYN。
- **データバス双方向化**: U13 を 74LVC245(3.3V、B側5V入力対応)に変更、DIR=R/W。U17(74LVC1G02)で OE_N = NOT(RW_N OR OE1) とし、CPU の書き込みを RP2350 が読めるようにする(ゲーム中の音源書き込みの記録用)。
- 裏面の 7 個のコンデンサを表面へ(全部品を表面実装、手半田は J11 など)。
- 水晶 Y1 を RP2350 の XIN/XOUT の真下へ。
- 電源ネットに Power ネットクラス(0.25mm)を設定し、配線後に広げる予定。

`docs/` の図と DRC は RevE4 のまま(未更新)。
