# FC-EXPSYNTH (Rev.E2 draft) — 92x60mm、表面SMD+裏面7個を手半田

RevE1 からの変更版。ファミコン拡張音源カセット(VRC6/VRC7/N163)を本物のチップで鳴らす中継カートリッジ基板で、RP2350BがカートリッジROMを装う。

## RevE1 からの変更点
- **配線が完了**: KiCad DRC(同梱の `.kicad_pro` ルールで実行)で未接続0・クリアランス違反0・短絡0・穴間隔違反0。
- **配線ルールを細線化**: 既定ネットクラスを トラック/クリアランス 0.1mm、ビア 0.45/0.2mm に変更(E1は0.15mm、0.5/0.25mm)。`min_hole_clearance` は 0.2mm に設定(KiCad既定は0.25mm)。
- **裏面コンデンサ7個を手半田**: C2, C6, C7, C8, C12, C13, C14 を裏面(U1の真裏)へ移し、0603に変更(4.7uのC6/C7も0603)。JLCPCBへ出す実装は表面のみ(片面)。裏面の7個は別途用意して手半田する(BOM末尾の2行)。
- **J14(予備GPIOヘッダ)を 2x08 → 2x04 に縮小**: GPIO38, 39, 41, 42, 28, 29 + 3V3 + GND。GPIO30, 31, 43〜47 はヘッダへ出さず、U1のピンのみ(QFN周りの混雑緩和)。
- バス用GPIO(GPIO1〜27)の割り当ては変更なし(ファームが GPIO0〜31 を一括読みするため)。

## 状態(正直な現状)
- DRC(`docs/drc.rpt`)の残り: silk系警告(silk_over_copper 32 / silk_overlap 29)、lib_footprint_issues 95(ライブラリ差異)、courtyards_overlap 1(J10とJ4)、track_dangling 1(+3V3の0.29mm余り線、警告のみ)。
- **C12のGNDパッド内にビア(44.4, 21.35)がある**(裏面のGND銅箔の島をGND層へつなぐため)。手半田でハンダが穴へ流れる可能性あり。
- 差し込み部・上辺パッド帯のルール(ビア禁止/外層の線禁止)はRevE1と同じ。
- 電源線(+3V3/+1V1/+5V)も0.1mmの線で配線されている部分がある(Powerネットクラスは未割り当て)。**電流容量・電源品質は未検証**。
- 回路図ERC未実施。ファームは実機未検証。

- 接触指フットプリント(J10)から、差し込み部全体のソルダーマスク開口(表裏の四角形)を削除。各指パッドは自前のマスク開口を持つ。これで solder_mask_bridge は0件(以前は90件)。

## 未確認事項
- JLCPCBの能力は公式ページの記載(4層: 線幅/間隔0.09mm、ビア穴0.2mm・径0.45mm以上は追加費用なし)による。実際の見積り・ゴールドフィンガー/面取り指定との両立・エコノミー実装の可否は未確認。
- 実機タイミング、スロットフットプリント(仮寸法)、LCSC部品番号、RP2350B A4ステッピング/5Vトレラント条件、N163/VRC7レジスタ詳細は未確認(RevE1と同じ)。
- 裏面コンデンサの位置はU1直下。デカップリングとして十分かの検証なし。

## 再生成
`scripts/gen_sch.py`(回路図) → `kicad-cli sch export netlist`(fc.net) → `scripts/build_pcb.py`(配置) → Freerouting(`rr.sh`等、RevE1と同じ) → `scripts/route_fix2.py`(残りを自作探索で補完、`HARD=1` で他の線をはがさない) → `scripts/finalize.py`(重複ビア整理・GND島の接続)。再生成の結果は実行ごとに変わる(自動配線の乱数性)ので、確定した配線はこのフォルダの `FC-EXPSYNTH.kicad_pcb` を正とする。
