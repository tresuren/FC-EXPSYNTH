# FC-EXPSYNTH (Rev.E1 draft) — 92x60mm, 片面SMD

ファミコン拡張音源カセット(VRC6/VRC7/N163)を本物のチップで鳴らす中継カートリッジ基板。RP2350BがカートリッジROMを装う。本体の6502/2A03が MCU 生成コードを実行して拡張カセットのレジスタへ書き込む。

## 状態(正直な現状)
- 回路図: 完成(ネットリスト 95部品/193ネット整合チェック済、KiCad ERC は未実施)
- 基板: 92x60mm / 4層 / 1.2mm。SMD部品は上面のみ(TP1-8は裏面パッドのみ)。拡張コネクタ(J11)は上辺の表30+裏30パッド(2.54mmピッチ、仮寸法1.5x3.0mm)に、2x30スルーホール式カードエッジの脚を曲げて挟み込み手半田する想定(実部品の脚寸法で要調整)。
- 配線: Freerouting(API経由)で自動配線。**未接続7件が残っている**(DRC unconnected_items: U1(QFN)周辺の +1V1、GPIO16/19/24/34、GND(J13)の一部)。クリアランス違反/短絡は0件(KiCadでプロジェクトファイルごと開いた場合。ネットクラス既定: クリアランス/トラック0.15mm、ビア0.5/0.25mm)。+3V3は電源面ではなく通常配線(0.15mm)。
- 差し込み部(下辺のファミコン接触ピン側、根元から先端まで): 外層は各指の真上へまっすぐ出る線以外の配線・ビアを禁止(ルールエリア NOTRACK_*/NOVIA_*)。指の間や指の上の帯を横切る線なし。内層の線もなし。
- サイズ比較(同条件の自動配線): 高さ60mm → 未接続7件 / 65mm → 未接続5件。差はわずかで、ボトルネックは基板サイズではなくU1(QFN 0.4mmピッチ)周辺の引き出し。`H_MM=65 python3 scripts/build_pcb.py` で高さを変えて再生成可能。
- 上辺(拡張コネクタ用パッド帯 y<4.8mm): ビア禁止。
- 手順(hardware/RevE1 で実行): `python3 scripts/build_pcb.py`(配置) → `FR_JAR=... scripts/rr.sh`(配線) → `python3 scripts/grab.py`(結果取得) → `python3 scripts/imp.py`(KiCad取り込み)。
- 旧版(92x105, 垂直スロット, 配線なし)は git履歴(最初のコミット前の版はなし)
- ファーム: stage1_bus_test(VRC6 440Hz)は pico-sdk でビルド確認済(uf2)。**実機未検証**。

## 未確認事項
- 実機タイミング(アドレス→D出力→M2↓)は未測定(推定100–150ns)
- スロットフットプリント(FC_Slot_60)は仮。実部品データシートで要確認
- JLCPCB: 1.2mm+ENIG+面取り+SMT の組合せ可否、LCSC部品番号は未確認
- RP2350B A4ステッピング入手性/5Vトレラント条件(IOVDD給電時)
- N163/VRC7レジスタ詳細、45/46番ピン音声パススルー
- 基板上のRP2350周辺部は Raspberry Pi 公式 minimal design を流用(ライセンス/帰属表記を確認)。fc-magicon を参考にした。

## テスト手順(stage1)
1. 拡張カセット無しで書込み: build/fc_stage1_bus_test.uf2 を BOOTSEL で書込む
2. VRC6カセットをスロットへ、AV Famicomに挿して電源
3. 440Hz のパルス音が鳴るか確認(EN_N=GPIO27はループ開始後にLow)

## 寸法メモ(ユーザー実測)
- 最大カセット幅92mm = 基板幅。スロット厚17.5mm、差し込み10.7mmは妥当との見立て。USB-C/microSDは上部配置でスロット外。
